# AI 摄影教练 — 已确认设计

用户已确认用途：点评本次拍摄效果、指出可改进之处，不是AI生成照片。

- 入口：照片回看中的“AI 摄影教练”。每次主动点击并确认发送。
- 输入：该照片≤1024px的JPEG、当时拍摄参数、可选拍摄意图。
- 输出：整体效果、两点优点、有证据的问题、三条优先改进建议、不确定性。仅文字，不自动修改参数。
- 云端：用户自带OpenAI API key，经同源Vercel函数转发到固定官方端点；模型可填写。
- 本地：Node loopback服务器，同源检查与随机会话令牌；可选API key或已登录Codex CLI。CLI采用临时只读目录、禁用shell工具、忽略用户配置、不留会话记录，结束清理本应用临时图片。
- 边界：CLI本地调用不是离线推理；模型/服务方数据政策仍适用。第一版支持OpenAI API，不声称兼容任意厂商key。
- 隐私：key仅页面内存，不放localStorage、JSON方案、照片、日志或仓库。照片/点评保留本次页面会话。响应按纯文本显示，禁止HTML执行。
- 失败：未同意不发送，缺key不发送；无效模型/额度/鉴权/超时明确报错；允许取消，不承诺取消一定避免费用。不自动切换账户或服务。
- 验收：适配器和HTTP鉴权测试、浏览器照片绑定/错误/手机布局、本机CLI真实图片点评；未提供用户API key时API成功路径使用标记清楚的测试替身，不声称真实API已验收。
