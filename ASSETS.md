# Character assets / 模型来源

Characters and hair: Quaternius, **Universal Base Characters**, CC0 1.0.
Official source and license: https://quaternius.com/packs/universalbasecharacters.html

Clothing: Quaternius, **Modular Character Outfits – Fantasy**, CC0 1.0.
Official source and license: https://quaternius.itch.io/modular-character-outfits-fantasy

CC0 legal terms: https://creativecommons.org/publicdomain/zero/1.0/legalcode

The official itch.io download returned HTTP 429 during this import. Files were
obtained from the public redistribution in lord3nd3r/ffxi-browser, pinned commit
`d65cd213cffb9c0ef17e3f70a6a46ea82ba47dfa`, public/models/chars/.
The author's CC0 declaration is authoritative; the mirror is a transport source.
Per-file SHA-256 hashes and exact source are recorded in assets/models/manifest.json.
Run `node scripts/fetch-models.js` only to reproduce the pinned import.

Runtime adaptations: base body is cropped to head/neck and hands and combined with
the matching outfit; glove geometry is trimmed, clothing base-color maps replaced
with original solid materials, skeleton arms posed, hair/materials recolored. Display
names Mira and Noah are local artistic labels, not identities of real people.
These are stylized game meshes, not photogrammetry or calibrated human skin.
Model shape is not a claim of anatomical or photographic ground truth.

All background geometry is original procedural work, covered by the repository
MIT license. No external texture service, CDN or remote runtime model request.
Original fallback mannequin is also MIT. The MIT license does not replace the
CC0 dedication of the third-party assets. Three.js license: THREE-LICENSE.txt.
